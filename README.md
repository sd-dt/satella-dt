## 这是什么

**Satella** 是一个纯客户端的 Fabric 实用模组（内部 mod id 仍为 `satella`），把「自动交易」和一堆自动化小工具做在了一起。

本仓库是 **基于 `satella-mc26.2-1.0.0+mc26.2` 的修改版本**，源码为 Minecraft **26.2**（26.x 起官方名称即运行时名称，不再需要 mappings）构建线，用 Fabric Loom + JDK 25 构建。

> 全部功能都在客户端实现，**不需要服务端安装**；使用时请遵守你所游玩服务器的规则。

## 功能一览

### 自动交易

| 功能 | 说明 |
|---|---|
| **后台自动交易** | 配置目标物品后，无需一直开着村民界面即可自动购买；支持「单次交易」与「自动轮询」两种模式 |
| **目标跟踪** | 交易目标用村民 UUID 跟踪，退出重进后高亮与状态不丢失 |
| **定时刷新交易界面** | 每 N 游戏刻关闭一次容器，让服务端刷新交易列表（0 = 不刷新） |
| **交易 GUI 开关** | 可显示真正的村民交易界面，也可隐藏界面后台交易 |
| **产物处理** | 成交结果可自动丢弃 |

### 自动化（合成 / 切石）

| 功能 | 说明 |
|---|---|
| **全自动合成** | 扫描背包 → 建材料表 → 按缺口补料 → 循环取出产物；材料按数量记账，半堆不超过缺口才取 |
| **全自动切石** | 把配置的输入物品切成输出成品后丢弃 |
| **残差合成** | 把「合成残余」并入自动化周期：物品堆数量低于阈值时跳过 |
| **界面开关** | 工作台/切石机界面可显示也可隐藏（隐藏时后台执行） |

### 物品保护

| 功能 | 说明 |
|---|---|
| **拦截目标物品丢弃** | 白名单语义：列表内的物品只能通过「光标移出界面点击丢弃」丢弃；手持 Q / Ctrl+Q、背包与容器内 Q / Ctrl+Q、创造模式物品栏内丢弃全部拦截 |

### 战斗辅助

| 功能 | 说明 |
|---|---|
| **更NB的弩** | 手持弩长按右键时持续使用并按周期重复右键（周期可配）；容器打开或投影打印机自动补货期间自动暂停连射 |
| **三叉戟交互三模式** | 「工具优先 / 可交互方块优先 / 放置方块优先」三选一（见下） |
| **副手食物** | 主手激流三叉戟、副手有食物时可选「优先进食」：压制激流、交给原版进食，吃完到松开右键前都不会再飞出 |

### 交互与光效

| 功能 | 说明 |
|---|---|
| **三叉戟交互** | **工具优先**——任何方块前都使用工具（激流三叉戟 / 已蓄力弩 / 有箭的弓）；**可交互方块优先**（默认）——可交互方块正常交互，不可交互方块才触发激流；**放置方块优先**——不触发激流，方块交互交给原版，副手方块照常放置 |
| **附魔显示颜色** | 19 种预设光效颜色（含彩虹、柔和原版、关闭光效） |
| **光效形态** | **炫酷**——光效只保留在亮网格线上，图案化、可消除自定义模型（如脸部材质包）在眼睛部位的闪烁；**默认**——完整的整体光膜效果 |

### `/st` 定位器

纯客户端的群系与结构定位器（移植 Datapack Map 算法）：`/st anystructure`、`/st anybiome` 就近多结构/多群系查询、多环定位规则（种子 + 数据包子集）、可视化规则编辑器（`/st rules`），查询结果可输出 Xaero 航点串、点击即导入。

### 兼容层

| 功能 | 说明 |
|---|---|
| **服务器快捷潜影盒兼容** | 让 Item Scroller / Inventory Profiles Next / Tweakeroo 忽略指定潜影盒组件（默认 `minecraft:custom_data`），名单在 `config/satella/ignored-components.txt` |
| **打印机补货暂停** | 检测 litematica-printer 的「快捷潜影盒-自动补货」是否进行中，期间自动暂停弩连射 |
| **中文 / 英文** | 内置 `zh_cn` 与 `en_us` 语言文件 |

## 相比 `satella-mc26.2-1.0.0+mc26.2` 的改动

| 改动 | 说明 |
|---|---|
| **三叉戟交互：两模式 → 三模式** | 原来的「工具交互优先级」（工具优先 / 交互优先）改为「三叉戟交互」：工具优先 / **可交互方块优先**（默认，最接近原版）/ **放置方块优先**（不触发激流、副手方块优先）；旧配置项会自动迁移 |
| **新增「副手食物」** | 「优先激流 / 优先进食」，按钮就在「三叉戟交互」下面；进食完全交给原版流程，避免「有动画但吃不下、停下放激流」 |
| **陆地激流补偿** | 有激流附魔但不在水中时原版 `use()` 会提前返回 FAIL、松手发不出 RELEASE_USE_ITEM；现在会补上使用状态，服务端放行时陆地也能正常放激流 |
| **盔甲光效修复** | 移除了把**物品**光效贴图套到**盔甲**上的覆盖，盔甲光效完全走原版（物品的颜色/形态功能不受影响） |
| **本地化与文案** | 补齐语言文件，新增的三叉戟模式与副手食物都有中英文键 |

> 模组本体、贴图与主要功能来自 Satella 原作者；本仓库只做上述改动。

## 安装

1. 需要 Minecraft **26.2** + Fabric Loader（≥ 0.19.3）。
2. 必需依赖：[Fabric API](https://modrinth.com/mod/fabric-api)、[MaLiLib](https://modrinth.com/mod/malilib)（`>= 0.29.2- < 0.30.0-`，配置界面与热键框架）。
3. 可选依赖：[Mod Menu](https://modrinth.com/mod/modmenu)（配置入口）、[Item Scroller](https://modrinth.com/mod/item-scroller) / [Tweakeroo](https://modrinth.com/mod/tweakeroo) / Inventory Profiles Next（只影响「服务器快捷潜影盒兼容」这一项）。
4. 把 Release 里的 **`satella-dt-1.0.0-mc26.2.jar`**（自己构建则是 `build\libs\satella-mc26.2-1.0.0+mc26.2.jar`）放进 `.minecraft/mods/`；**同一时间只能有一个 satella**。

## 从源码构建

本仓库是一个标准的 Fabric Loom 工程（26.2 免 mappings）：

```powershell
# 需要 JDK 25（26.2 的 class 版本为 69）
$env:JAVA_HOME = '<你的 JDK 25 路径>'
.\gradlew.bat build --no-daemon --console=plain
# 产物：build\libs\satella-mc26.2-1.0.0+mc26.2.jar
```

依赖版本写在 `gradle.properties`：`minecraft_version=26.2`、`loader_version=0.19.3`、`fabric_api_version=0.161.0+26.2`、`malilib_version=0.29.6`、`modmenu_version=20.0.1`。
Gradle wrapper 指向腾讯镜像（`mirrors.cloud.tencent.com`），首次构建会自动下载 Gradle 9.6。

## 配置

游戏内：**MaLiLib 配置界面 → Satella**（或 Mod Menu 里的配置按钮），分「交易 / 自动化 / 杂项」三页；
配置文件：`.minecraft/config/satella/Satella.json`。常用项：

| 键 | 说明 |
|---|---|
| `启用自动交易` / `交易模式` / `交易间隔` | 自动交易总开关、单次或自动轮询、轮询间隔 |
| `输入物品1/2` / `输出物品` | 交易筛选：支持显示名、物品 id、省略 `minecraft:` 的 id |
| `全自动合成` 系列 | 自动化开关、模式（合成/切石）、周期、残余阈值 |
| `拦截目标物品丢弃` | 物品保护白名单 |
| `更NB的弩` / `更NB的弩周期` | 弩连射与周期 |
| **`三叉戟交互`** | 工具优先 / 可交互方块优先（默认）/ 放置方块优先 |
| **`副手食物`** | 优先激流（默认）/ 优先进食 |
| `附魔显示颜色` / `光效形态` | 附魔光效颜色与形态（只影响物品） |
| `服务器快捷潜影盒兼容` | 配合 `config/satella/ignored-components.txt` |
| `多环定位规则` | `/st rules` 可视化编辑器 |

> 想在游戏里确认「三叉戟交互」的判定链？在游戏目录建一个空的 `satella-diag.txt`，每次工具接管都会追加一行判定细节。
